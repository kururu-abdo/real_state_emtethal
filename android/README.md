# امتثال العقاري — Android

واجهة Android أصلية باستخدام Kotlin + Jetpack Compose، مرتبطة بـFastAPI الموجود في هذا المستودع. العربية هي اللغة الافتراضية. تعرض اللغتين رأسياً على الهاتف وجنباً إلى جنب على الشاشات الواسعة.

## التشغيل على Android Studio

1. نزّل هذا المستودع وافتح Terminal داخل مجلد `android`.
2. نفّذ `sh bootstrap-gradle.sh` مرة واحدة (macOS/Linux أو Git Bash على Windows). يحتاج Git وcurl. ينزل Gradle Wrapper الرسمي ويتحقق من Git blob ID المثبّت؛ ملف JAR الثنائي غير مضمن في المستودع.
3. افتح **مجلد android** في Android Studio، وليس جذر مشروع Python.
4. اختر JDK 17 للـGradle وثبّت Android SDK 35 وBuild Tools 35.0.0 عند الطلب.
5. انتظر Gradle Sync، ثم Run على جهاز Android 8.0/API 26 أو أحدث.

```bash
sh bootstrap-gradle.sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

المشروع يستخدم AGP 8.9.2، Gradle 8.11.1، Kotlin 2.1.20 وCompose BOM 2025.04.01. هذه إصدارات مثبتة وليست ادعاءً بأنها أحدث الإصدارات.

## تشغيل السيرفر والاتصال

من جذر المستودع، جهّز `.env` بمفتاحين مختلفين حسب README الرئيسي ثم شغّل:

```bash
docker compose up --build
```

على **محاكي Android Studio**:

```text
http://10.0.2.2:8000/
```

على **جوال حقيقي متصل بـUSB**، فعّل USB debugging ثم:

```bash
adb reverse tcp:8000 tcp:8000
```

واستخدم في التطبيق:

```text
http://127.0.0.1:8000/
```

إذا كان هناك أكثر من جهاز، استخدم `adb -s DEVICE_SERIAL reverse tcp:8000 tcp:8000`.

الـDocker Compose الافتراضي يربط السيرفر بـ127.0.0.1 على الكمبيوتر. عنوان Wi-Fi للكمبيوتر لن يعمل بهذا الإعداد؛ استخدم USB reverse أو سيرفر HTTPS متاحاً للجوال. HTTP مسموح في Debug فقط، ونسخة Release تتطلب HTTPS.

الصق قيمة `ANALYST_API_KEY` في شاشة الاتصال ثم اضغط **اتصال وتحميل العقود**. للاعتماد أو الرفض غيّر المفتاح إلى `REVIEWER_API_KEY`. نفس عنوان السيرفر يحتفظ بمسودة المراجعة الموجودة في الذاكرة عند تغيير المفتاح.

## تجربة المسار

1. افتح «عقد جديد» واضغط «تعبئة مثال تجريبي وإرفاق مستنده».
2. راجع البيانات ثم اضغط «استخراج وصياغة العقد».
3. راجع الملخص والأدلة والنقاط غير المحسومة، وعدّل بيانات العقد والبنود باللغتين.
4. في Demo، استبدل `REVIEW_REQUIRED` في **كل نص ومرجع** بنص تجريبي واضح؛ لا تستخدم هذا لعقد حقيقي.
5. افتح إعدادات الاتصال وغيّر المفتاح إلى مفتاح المراجع ثم اتصل مجدداً بنفس السيرفر.
6. أكمل الإقرارات الثلاثة ومرجع حساب الضمان وملاحظة المراجعة، ثم اعتمد أو ارفض.
7. بعد الاعتماد اضغط «حفظ PDF» واختر المكان عبر منتقي ملفات Android.

تُطبق صلاحيات الاعتماد وقواعد المطابقة في السيرفر. التطبيق لا يتجاوز المراجعة ولا ينشئ عقداً معتمداً محلياً.

## ما يتضمنه

- قائمة العقود مع بحث وحالات وعدّادات وتحديث يدوي.
- رفع عدة مستندات عبر منتقي النظام بدون صلاحية وصول شاملة للتخزين.
- تحقق من حقول المشروع، تاريخ التسليم والسعر قبل الإرسال.
- تحرير العربية RTL والإنجليزية LTR ومراجع البنود.
- تأكيد الاعتماد/الرفض وإرسال `expected_revision` والإقرارات للسيرفر.
- معالجة 401/403/409/422، وحفظ النص المعدّل عند فشل طلب المراجعة.
- تنزيل PDF المصادق عليه باستخدام مفتاح الدخول، والحفظ بالمكان الذي يختاره المستخدم.
- اختبارات JVM للـJSON وطلبات الشبكة والصلاحيات الظاهرة والتحقق من المدخلات.
- GitHub Actions للبناء والاختبار وlint وإرفاق Debug APK عند النجاح.

## حدود النسخة

- يحتاج السيرفر؛ لا توجد قاعدة عقود offline أو push notifications. استخدم التحديث اليدوي لاستعادة الحالة.
- المفتاح والمسودات في ذاكرة ViewModel فقط، وتبقى عند تدوير الشاشة لكن تضيع عند إنهاء عملية التطبيق. العقود المرسلة تبقى بالسيرفر. يُحفظ عنوان السيرفر فقط في SharedPreferences.
- المسودات غير المرسلة ليست محفوظة بالسيرفر. تظهر رسالة قبل تحديثها من السيرفر أو مغادرة المراجعة.
- لا يرسل التطبيق طلبات التعديل تلقائياً مرة ثانية عند انقطاع الشبكة. افحص قائمة العقود قبل تكرار طلب ربما وصل للسيرفر.
- صلاحيات النظام الحالية مفاتيح أدوار مشتركة، وليست حسابات مستخدمين فردية. إضافة SSO/OIDC تحتاج تطوير backend أيضاً.
- الصور تتطلب LLM_MODE=live؛ PDF الممسوح يحتاج OCR أولاً وفق backend الحالي.
- Release غير موقع بمفتاح نشر؛ لا توجد مفاتيح أو أسرار مضمنة. Debug APK مخصص للتجربة.
- يتم تعطيل لقطات الشاشة ونسخ التطبيق الاحتياطية لحماية محتوى المراجعة ومفتاح الدخول.

## APK

في GitHub افتح **Actions → Android build → التشغيل الناجح → Artifacts** ثم نزّل `emtethal-real-estate-debug-apk`، فك الضغط وثبّت `app-debug.apk`. وجود ملف workflow لا يعني نجاح البناء؛ راجع نتيجة التشغيل.
